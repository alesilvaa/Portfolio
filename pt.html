Sobre Mim Minha Startup
Perfil

Criando soluções escaláveis.

Sou um Desenvolvedor de Software do Paraguai, com forte foco no desenvolvimento iOS e arquitetura de software moderna. Minha experiência consiste em projetar e construir aplicativos robustos para sistemas em produção real, incluindo aplicativos bancários e financeiros seguros.

Minha abordagem para o software é baseada na "clean architecture", princípios SOLID e um profundo entendimento de ecossistemas full-stack. Seja criando uma experiência mobile fluida com SwiftUI, projetando uma API REST segura em Spring Boot, ou construindo uma interface web responsiva com Next.js, minha prioridade é escrever código eficiente e fácil de manter.

Essa paixão por resolver problemas reais me levou a fundar a Manageopy, minha startup onde desenvolvemos software sob medida, automações e plataformas digitais projetadas especificamente para ajudar as PMEs (PyMEs) locais a crescer e otimizar suas operações diárias.
